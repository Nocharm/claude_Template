# UI — 형광펜 노트

목업 (Design 캔버스, 비공개): https://claude.ai/artifact/RN9FvY1R45QLtFPpmdC9fk

## 컨셉

줄 노트에 일기를 읽고, 외울 표현은 형광펜으로 칠해져 있다. 칠한 곳을 탭하면 설명·발음·영상·응용이 펼쳐지고, 표현끼리는 맵으로 이어진다. 책의 다이어리 감성은 살리되 책 디자인을 복제하지 않는다.

## 디자인 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| Paper | `#FAF8F2` | 바탕 |
| Rule | `#E6E1D6` | 줄·테두리 |
| Ink | `#1F2925` | 본문·주요 버튼 |
| Sub | `#5D6762` | 보조 텍스트 |
| Marker | `#CDEFDC` | 형광펜 하이라이트 |
| Green | `#1E7F55` | 표현 강조·정답·활성 탭 |
| Tangerine | `#E8743B` | 복습·연속 학습·대조 관계 |

- 서체: **Gaegu** (제목·일기 본문, 손글씨) + **Noto Sans KR** (UI·해설). 본문 15px, 보조 13px.
- 모서리: 카드 16px, 버튼 14px. 터치 영역 44px 이상.
- 관계 태그: 유사(Marker) · 대조(Tangerine 연한색) · 다른 쓰임(회색) · 같은 문장(외곽선).

## 화면

하단 탭 5개: **홈 · 읽기 · 맵 · 복습 · 웹툰**. 상세·퀴즈 화면은 탭 대신 하단 액션 바.

| # | 화면 | 핵심 요소 |
|---|---|---|
| 1 | 홈 | 연속 학습일, 이어 읽기(DAY 카드), 오늘 복습 수 + 시작, 오늘의 표현, 새 웹툰, 책 추가 |
| 2 | DAY 읽기 | 줄 노트 본문 + 형광펜 표현(탭 → 상세), 원문/문장별 해석 전환, 전체 듣기, 맵·퀴즈 진입 |
| 3 | 표현 상세 | 표현 · 뜻, 억양 선택 듣기(미국/영국/호주/인도, 0.75×), 해설 + 예문, 연결 표현, AI 응용(상황 선택·첨삭), 실제 영상(YouGlish), 복습 카드 추가 |
| 4 | 표현 맵 | 범위 필터(DAY/구간/책 전체), 중심 표현 + 관계별 노드, 선택 노드 요약 카드 |
| 5 | 복습 퀴즈 | 진행률, 유형(빈칸/한→영/듣고 쓰기), 한글 문맥 + 빈칸 문장, 답 입력, 정답 피드백 + 다음 복습 시점 |
| 6 | 10컷 웹툰 | 사용 표현 칩, 세로 스크롤 패널(SVG 캐릭터 + HTML 말풍선, 표현 하이라이트), 다시 그리기 |

## 웹툰 원칙

- 고정 캐릭터 2명(일기 화자 · 남편)을 SVG 파츠(얼굴·머리·표정·옷 색)로 정의 → Claude는 장면 구성·표정·포즈만 지정해 10컷 내내 일관성 유지.
- 말풍선은 SVG 밖 HTML 오버레이 — 표현 하이라이트·TTS 연결이 쉽다.
