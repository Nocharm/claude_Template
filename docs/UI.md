# UI — 말랑 형광펜 다이어리

목업 (Design 캔버스, 비공개): https://claude.ai/artifact/RN9FvY1R45QLtFPpmdC9fk — 모션 데모 보드는 Play로 직접 눌러볼 수 있다. 원본: [`docs/mockup/`](mockup/).

## 컨셉

줄 노트에 일기를 읽고, 외울 표현은 형광펜이 그어지듯 나타난다. 문장 카드는 뒤집으면 해석이 나오고, 매일 목표를 채우면 달력에 도장이 찍힌다. 손글씨는 **제목 · 표현 · 스티커**에만, 오래 읽는 해설과 버튼은 둥글고 눈이 편한 고딕으로 쓴다. 책의 다이어리 감성은 살리되 책 디자인을 복제하지 않는다.

## 서체 — 3계열

| 계열 | 서체 | 쓰는 곳 |
|---|---|---|
| 손글씨 | **Patrick Hand** (영문) + **Gamja Flower** (한글) | 일기 본문, 표현, 카드 앞면, 스티커, 칭찬 문구 |
| 시스템 | iPhone 기본 (SF Pro + Apple SD Gothic Neo) | 해설, 해석, 버튼, 라벨 — 오래 읽는 글 |
| 강조 | **Gmarket Sans** (Bold/Medium) | 화면 제목, 숫자(XP·연속일·레벨), 배지 |

- 손글씨 스택 `'Patrick Hand', 'Gamja Flower', cursive` — 영문은 Patrick Hand, 한글은 자동으로 Gamja Flower (Google Fonts).
- 시스템 스택 `system-ui, -apple-system, 'Apple SD Gothic Neo', sans-serif` — 다운로드 없음, 가독성 최상.
- Gmarket Sans는 Google Fonts에 없어 jsDelivr(눈누) CDN에서 로드 — 로드 실패 시 시스템 서체로 대체.
- 본문 15px, 보조 13px. 손글씨는 시각 크기가 작아 시스템 서체보다 4–6px 크게.
- 목업은 Gmarket Sans 대신 손글씨 제목으로 그려져 있다 — 구현이 이 표를 따른다.

모서리: 카드 16–22px, 버튼 14px. 카드에 `4px 4px 0` 잉크색 그림자로 스티커 느낌. 터치 영역 44px 이상.

## 모션

| 이름 | 트리거 | 동작 |
|---|---|---|
| 카드 뒤집기 | 문장 카드 탭 | Y축 180° 회전 0.55s, 살짝 튕기는 easing. 앞면 영어 · 뒷면 해석 + 핵심 해설 |
| 형광펜 긋기 | 표현이 화면에 처음 보일 때 | 하이라이트가 왼→오로 0.7s 동안 그어짐 |
| 도장 쾅 | 오늘 목표 달성 | 2.2배 크기에서 회전하며 찍힘 0.45s + "+30 XP"가 떠오름 |
| +XP 톡 | 정답·학습 행동 | 점수가 위로 떠오르며 사라짐 1.2s |
| 스와이프 | 복습 카드 | 왼쪽 = 다시, 오른쪽 = 알아요. 날아가며 다음 카드 등장 |

기기의 "동작 줄이기" 설정(`prefers-reduced-motion`)이 켜져 있으면 모든 모션을 즉시 전환/페이드로 대체한다.

## 매일 학습 루프 (게이미피케이션)

원칙: **보상은 크게, 벌점은 없다.** 놓친 날은 "다시 시작"만 유도한다.

- **오늘 목표** — 기본 복습 10 + 새 문장 5 (설정에서 조절). 홈 상단 진행 링으로 표시.
- **도장 달력** — 목표 달성일 = 도장, 일부 학습 = 작은 점, 쉼표 사용일 = 하늘색.
- **스트릭 쉼표** — 주 1회 자동 사용, 하루 쉬어도 연속 유지.
- **XP · 레벨** — 레벨 이름은 노트 테마 (새 노트 → 꾸준한 메모러 → …). 레벨업 보상은 형광펜 색, 웹툰 캐릭터 의상 등 꾸미기 해금.
- **마스터 표현** — 간격 반복 간격이 21일 이상이 된 표현 수. 실력 지표.
- **스티커북** — DAY 완주, 7/30/100일 연속, 첫 웹툰, 응용 문장 10개 등 수집.

| 행동 | XP |
|---|---|
| 새 문장 카드 학습 | +5 |
| 퀴즈 정답 (첫 시도 / 재시도) | +10 / +5 |
| 응용 문장 작성 · 첨삭 | +15 |
| 웹툰 10컷 완독 | +10 |
| 오늘 목표 달성 보너스 | +30 |
| DAY 완주 | +50 |

수치는 초기값 — 실제 사용해 보며 조정한다.

## 화면

하단 탭 5개: **홈 · 읽기 · 맵 · 복습 · 웹툰**. 상세·퀴즈·달력 화면은 탭 대신 뒤로 가기와 하단 액션 바.

| # | 화면 | 핵심 요소 |
|---|---|---|
| 1 | 홈 | 연속일 · 레벨 칩(→ 달력), 오늘 목표 링 + 남은 개수, 이어 읽기, 오늘 복습, 오늘의 표현, 새 웹툰 |
| 2 | DAY 읽기 | 줄 노트 본문 + 형광펜 표현(탭 → 상세), 원문/문장별 해석(카드 뒤집기) 전환, 전체 듣기 |
| 3 | 표현 상세 | 억양별 듣기(미국/영국/호주/인도, 0.75×), 해설 + 예문, 연결 표현, AI 응용, 실제 영상(YouGlish), 복습 카드 추가 |
| 4 | 표현 맵 | 범위 필터(DAY/구간/책 전체), 중심 표현 + 관계별 노드, 선택 노드 요약 |
| 5 | 복습 퀴즈 | 진행률, 유형(빈칸/한→영/듣고 쓰기), 정답 피드백 + 다음 복습 시점 |
| 6 | 10컷 웹툰 | 사용 표현 칩, 세로 스크롤 패널(SVG 캐릭터 + HTML 말풍선) |
| 7 | 도장 달력 | 레벨 · XP 바, 연속일 · 마스터 표현 · 이번 달 도장, 월 달력, 스티커북 |

## 웹툰 원칙

- 한국 웹툰 스타일 일러스트를 Gemini가 그림 (SVG 안에서 업그레이드). 고정 캐릭터 2명(미나 · 준)의 기준 이미지를 한 번 만들고 매 컷에 함께 넘겨 얼굴·옷을 유지.
- 그림에는 글자를 넣지 않고 위쪽 1/4을 비워 두게 한 뒤, 말풍선은 HTML로 얹는다 — 철자 정확, 표현 하이라이트·TTS 연결.
- 월·수·금 새벽 3시 자동 생성, 꺼져 있었으면 켜질 때 보충. 완독 +10 XP.
